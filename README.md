# Аналіз серцевого ритму

Навчальний вебзастосунок класифікує серію ударів за хвилину як нормальний ритм або аритмію.

- **Нормальний ритм** — інтервали між ударами майже рівні.
- **Аритмія** — інтервали суттєво нерівномірні.

Навчальні дані синтетичні. Застосунок **не призначений для медичної діагностики**: оцінки мережі не є ймовірністю захворювання, а крива на екрані — схематична візуалізація, не запис ЕКГ.

## Можливості

- генерація навчальних прикладів (від 250 до 10 000, спочатку 400);
- набір: усі, чисті або зашумлені приклади;
- епохи (від 100 до 5000, спочатку 2000) і швидкість навчання (від 0.01 до 0.99, спочатку 0.3);
- навчання у Web Worker, якщо браузер дозволяє, інакше порціями на головному потоці;
- прогрес і час генерації, навчання та розпізнавання;
- поділ даних 80/20: навчання і перевірка; точність рахується на перевірці;
- ввід серії bpm через кому: від 4 до 50 чисел у межах 20–250 (наприклад, `72, 68, 75, 71, 69, 73, 70, 68, 74`);
- тестові серії «Норма» і «Аритмія»;
- ковзаюче вікно по 4 інтервали; вердикт — середнє по вікнах;
- вкладка «Статистика»: метрики після навчання і журнал подій.

Мережа вчиться регулярності інтервалів, а не абсолютній частоті пульсу. Рівна брадикардія чи тахікардія класифікується як норма.

## Технології

- HTML, CSS, JavaScript
- React 18.3.1 (UMD, без збірки і без JSX — через `React.createElement` / `h()`)
- Tailwind CSS (browser build)
- Brain.js 1.6.1
- Canvas

Бібліотеки лежать у `vendor/`. Інтернет і npm не потрібні.

Код: https://github.com/yyyaniv/heart-checker

## Запуск

1. Скопіюйте папку проєкту разом із `vendor/`.
2. Відкрийте `index.html` у браузері.

Працює через `file://`. Альтернативи:

- VS Code: Live Server → Open with Live Server
- термінал у корені проєкту: `python3 -m http.server`, потім `http://localhost:8000`

Вкладки:

- **Аналіз** — навчання, серія bpm, візуалізація ритму, результат;
- **Статистика** — метрики, журнал і знімок останнього розпізнавання.

## Алгоритм

```
серія bpm (4–50 чисел) ──► секунди між ударами (60 / bpm)
                                    │
                                    ▼
                     вікна по 4 інтервали (крок 1)
                                    │
                                    ▼
              normalizeSequence ──► Brain.js (кожне вікно)
                                    │
                                    ▼
                    середнє оцінок по всіх вікнах
                                    │
                                    ▼
                          норма / аритмія
```

Мережа завжди отримує рівно 4 числа. Довша серія — лише спосіб вводу.

## Мережа

- архітектура: 4 входи → 8 прихованих → 2 виходи (`normal`, `arrhythmia`);
- активація: sigmoid;
- поріг похибки навчання: 0.005;
- перед навчанням і розпізнаванням однакова нормалізація: кожен інтервал ділиться на середнє вікна, потім стискається в `[0, 1]`.

Перевірка з консолі браузера:

```js
HeartApp.core.neuralNetwork.benchmarkNetwork([100, 500, 1000])
  .then(console.table);
```

## Обмеження

- навчальні дані синтетичні;
- мережа реагує на нерівномірність інтервалів, не на абсолютний bpm;
- React і Tailwind підключені як готові браузерні збірки;
- не для медичної діагностики.
