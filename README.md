# Heart Rhythm Neural Network Classifier

## Опис

Навчальний вебзастосунок для класифікації серцевого ритму за послідовністю R-R інтервалів:

- **Нормальний ритм** — інтервали майже рівні;
- **Аритмія** — інтервали суттєво нерівномірні.

Дані синтетичні. Застосунок **не призначений для медичної діагностики**.

## Завдання

Класифікувати bpm-серію як `normal` або `arrhythmia` за допомогою простої нейронної мережі (Brain.js), що завжди приймає рівно 4 числа.

## Можливості

- генерація synthetic training data (мінімум 250 прикладів, типово 400);
- вибір набору: усі, чисті або зашумлені приклади;
- налаштування кількості епох і швидкості навчання;
- навчання у Web Worker (якщо браузер дозволяє), інакше порціями на головному потоці;
- прогрес генерації (частка прикладів) і навчання (номер епохи);
- час генерації, навчання і розпізнавання на екрані;
- навчання нейронної мережі з прогрес-баром;
- ввід — bpm-серія довільної довжини (N ≥ 4) через кому (наприклад, `72, 68, 75, 71, 69, 73, 70, 68, 74`);
- тестові приклади: норма і явно нерегулярна серія;
- мережа розбиває серію на послідовні вікна по 4 (sliding window) і усереднює вердикт;
- класифікація та візуалізація confidence;
- візуалізація ритму (canvas, ECG-подібна крива з R-піками);
- статистика навчання та журнал подій на вкладці «Статистика».

## Технології

- HTML5 / CSS3 / JavaScript
- React 18 (UMD, **без збірки**, без JSX — через `React.createElement` / `h()`)
- Tailwind CSS (browser build)
- Brain.js 1.6.1
- HTML Canvas API

Усі бібліотеки лежать у папці `vendor/`. **Інтернет і npm не потрібні.**

Публічний код: https://github.com/yyyaniv/heart-checker

## Запуск

Найпростіший спосіб:

1. Скопіюйте папку проєкту.
2. Відкрийте файл `index.html` у браузері (подвійний клік або File → Open).

Працює через `file://` — Live Server не обовʼязковий.

Інтерфейс розрахований на **один екран** (без вертикального скролу на типових десктопних роздільностях). Вкладки:

- **Аналіз** — навчання, ввід bpm-серії, візуалізація ритму, результат;
- **Статистика** — метрики після навчання, журнал подій і знімок останнього прогнозу.

Альтернативи:

- VS Code: розширення **Live Server** → Open with Live Server
- термінал: `python3 -m http.server` у корені проєкту → відкрити `http://localhost:8000`

> Переконайтеся, що разом із `index.html` скопійована папка `vendor/` (react, react-dom, brain.js, tailwind).

## Алгоритм

```
bpm-серія (N ≥ 4, через кому) ──► bpm → R-R секунди
                                          │
                                          ▼
                         sliding window по 4 (stride 1)
                                          │
                                          ▼
                    normalizeSequence ──► Brain.js (кожне вікно)
                                          │
                                          ▼
                  усереднення confidence по всіх вікнах
                                          │
                                          ▼
                              Норма / Аритмія
```

Нейронна мережа **завжди** отримує рівно 4 числа за раз; серія довільної довжини — це лише спосіб вводу для користувача.

## Neural Network

- Архітектура: 4 входи → 8 hidden → 2 виходи (`normal`, `arrhythmia`)
- Активація: sigmoid
- Перед навчанням і перед predict використовується **однакова** нормалізація:
  - кожен інтервал ділиться на середнє послідовності (відносна форма ритму);
  - результат стискається в `[0, 1]` для sigmoid.

Так мережа вчиться нерівномірності, а не абсолютній тривалості інтервалів. Тому серії з низькою варіативністю (наприклад, стійка брадикардія/тахікардія з рівними інтервалами) класифікуються як `normal` — мережа не враховує абсолютний bpm, лише регулярність.

Benchmark (для наступних лабораторних) з консолі браузера:

```js
HeartApp.core.neuralNetwork.benchmarkNetwork([100, 500, 1000])
  .then(console.table);
```

## Обмеження

- навчальні дані **синтетичні**;
- мережа реагує лише на нерівномірність (CV) інтервалів, не на абсолютний bpm;
- React/Tailwind підключені як UMD/browser builds (режим навчального прототипу, не production-збірка);
- **не призначено для медичної діагностики**.
